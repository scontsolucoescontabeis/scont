O Gerador de Modelos cria documentos (termos, contratos, autorizações) a partir de modelos com variáveis — como {{empregado.nome_empregado}} — preenchidas automaticamente com dados de Empresas, Empregados, Sócios e Rubricas cadastrados no módulo RH, ou de uma planilha Excel enviada na hora. Um documento pode ser gerado avulso ou como parte de um "Evento" (ex: Admissão), que reúne vários modelos e gera todos de uma vez para os mesmos empregados.

Modelos

Como usar

  1. Na tela Modelos, clique em + Novo Modelo (ou "Editar" em um já existente).
  2. Informe o nome, uma descrição opcional, o Tipo (Por Registro ou Consolidado) e o Cabeçalho Padrão que o documento deve usar ao ser gerado.
  3. Marque as Fontes de Dados que o modelo vai usar: Empresas, Empregados, Sócios, Rubricas e/ou Planilha Excel. Cada fonte marcada libera um grupo de variáveis no painel acima do editor.
  4. Escreva o texto do documento no editor. Clique em qualquer variável do painel (ex: {{empregado.nome_empregado}}) para inseri-la na posição do cursor — não é preciso digitar as chaves manualmente.
  5. Formate o texto pela barra de ferramentas do editor (negrito, itálico, sublinhado, alinhamento, tamanho e tipo de fonte, inserir tabela). O botão Ver HTML alterna para o código-fonte do modelo, para ajustes finos.
  6. Se precisar de dados que não existem no sistema (ex: uma lista personalizada), suba uma planilha em "Planilha Excel — variáveis extras" dentro do próprio modal: cada coluna vira uma variável {{excel.NOME_DA_COLUNA}}.
  7. Clique em Salvar Modelo.

Funcionalidades

  • Tipo "Por Registro": gera um documento para cada empregado selecionado na geração (ou um por empresa, se o modelo não usar a fonte Empregados) — é o tipo usado para a maioria dos termos individuais.
  • Tipo "Consolidado": gera um único documento por empresa selecionada, não um por empregado. Se as fontes Empregados/Sócios/Rubricas estiverem marcadas, o documento usa o primeiro registro encontrado daquela empresa para preencher as variáveis — útil para documentos que falam da empresa como um todo, não de uma pessoa específica.
  • Variável ext ao lado de cada campo numérico: insere o valor por extenso (ex: salário "1500,00" vira "mil e quinhentos reais") em vez do número puro.
  • Variáveis de sistema sempre disponíveis: {{sistema.data_atual}} e {{sistema.data_atual_extenso}} (data do dia, por extenso).
  • Variáveis de planilha ({{excel.*}}) ficam disponíveis tanto quando "Planilha Excel" é marcada como fonte, quanto quando uma planilha extra é anexada só para aquele modelo — os dois casos aparecem no mesmo painel de variáveis.
  • Um modelo sem nenhuma fonte de banco de dados marcada, mas usando variáveis {{excel.*}}, funciona em modo "Excel puro": a geração pede só a planilha, sem passar pelos passos de Empresas/Empregados/Sócios/Rubricas.

Perguntas frequentes

Qual a diferença entre marcar "Planilha Excel" como fonte e anexar uma planilha só no modal do modelo?
São a mesma coisa em termos de variáveis disponíveis ({{excel.coluna}}). A diferença é o momento do upload: marcando a fonte, a planilha é enviada durante o assistente de Geração (um passo a mais no wizard, podendo trocar de planilha a cada geração); anexando no modal, a planilha fica fixa junto ao modelo.
Posso editar o HTML do modelo diretamente?
Sim, o botão "Ver HTML" no topo do editor alterna para o código-fonte. As duas visões (visual e HTML) editam o mesmo conteúdo.

Eventos

Como usar

  1. Na tela Eventos, clique em + Novo Evento.
  2. Informe o nome (ex: "Admissão") e uma descrição opcional.
  3. Na lista de "Modelos disponíveis", clique em + Adicionar em cada modelo que deve compor o evento.
  4. Na lista "Modelos do evento", use as setas ↑/↓ para definir a ordem em que os documentos serão gerados, ou ✕ para remover um modelo do evento.
  5. Clique em Salvar Evento.
  6. Para gerar, use o botão ⚡ Gerar no card do evento — o mesmo assistente de Geração é usado, mas produz todos os modelos do evento de uma vez para os mesmos empregados/empresas escolhidos.

Funcionalidades

  • Um evento não duplica os modelos: ele só referencia os modelos já cadastrados em Modelos, na ordem escolhida. Editar um modelo depois reflete em todos os eventos que o usam.
  • Excluir um evento não apaga os modelos individuais que o compunham.
  • Um evento só pode ser gerado se tiver pelo menos um modelo configurado (o botão "Gerar" fica desabilitado até lá).
  • Na geração, cada documento do evento sai com seu próprio cabeçalho (nome/logo da empresa + título daquele modelo específico), e cada modelo entra em página separada — tanto entre os modelos de um mesmo empregado, quanto entre um empregado e o próximo.

Gerar Documento

Como usar

  1. Abra Gerar no menu (ou clique em "⚡ Gerar" a partir de um card de Modelo ou de Evento) e siga os passos indicados na barra no topo da tela.
  2. Modelo: escolha o modelo (esse passo é pulado quando a geração parte de um Evento).
  3. Empresas: marque uma ou mais empresas. Aqui também é possível anexar/trocar/remover a logo de cada empresa — uma vez enviada, ela passa a aparecer automaticamente no cabeçalho de qualquer documento gerado para essa empresa dali em diante.
  4. Empregados / Sócios / Rubricas (só aparecem se o modelo usar essas fontes): todos os registros das empresas escolhidas já vêm pré-selecionados; use os botões "Todos"/"Nenhum" ou desmarque individualmente quem não deve entrar na geração.
  5. Planilha (só aparece se o modelo usar variáveis de Excel): envie o arquivo. A primeira linha deve ter os cabeçalhos — cada um vira uma variável {{excel.COLUNA}}.
  6. Exportar: revise a pré-visualização (setas "‹ Anterior" / "Próximo ›" percorrem cada documento que será gerado), escolha o tipo de cabeçalho e clique em 📄 Salvar PDF ou 📊 Exportar Excel.

Funcionalidades

  • Os passos do assistente mudam de acordo com as fontes marcadas no modelo (ou na união das fontes dos modelos de um evento) — um modelo que só usa Empresas e Empregados não mostra os passos de Sócios/Rubricas/Planilha.
  • Descartar registro: na pré-visualização, é possível remover da geração o documento que está sendo exibido no momento (ex: um empregado que não deve receber aquele termo) sem refazer os passos anteriores — ele some tanto do PDF quanto do Excel exportados.
  • Três opções de cabeçalho, escolhidas na hora de exportar: Completo (logo da empresa cliente, ou a marca "SCONT" se ela não tiver logo cadastrada, + nome da empresa + título do modelo), Neutro (nome da empresa + título do modelo, com "SCONT Soluções Contábeis" discretamente no canto) e Sem Cabeçalho (só o conteúdo do modelo).
  • "Ajustar para caber em 1 página": encolhe proporcionalmente o conteúdo de cada documento que ultrapassaria uma folha A4, sem nunca ampliar o que já cabe.
  • Múltiplas empresas na mesma geração: ao exportar em PDF, o sistema abre uma janela de impressão separada por empresa (evitando misturar documentos de clientes diferentes em um único arquivo). Ao exportar em Excel, todos os registros saem juntos em uma única planilha, com uma coluna extra documento_gerado contendo o texto final de cada documento.
  • Salvar PDF abre a caixa de impressão do navegador — o documento é salvo escolhendo "Salvar como PDF" no destino da impressão, não é um download automático. Recomenda-se desmarcar "Cabeçalhos e rodapés" na caixa de impressão para não sair a data/URL do navegador na folha.
  • Toda geração (PDF ou Excel) fica registrada no Histórico, mesmo sem alterar nenhum cadastro.

Memórias de cálculo

Geração em modo "Excel puro" (modelo sem nenhuma fonte de Empresas/Empregados/Sócios/Rubricas, só variáveis {{excel.*}}): o sistema tenta identificar automaticamente, pelo nome do cabeçalho da planilha, qual coluna indica a empresa de cada linha (reconhece cabeçalhos como "Empresa", "Cliente", "Razão Social", "Nome Fantasia" etc.). Se encontrar, gera um PDF separado por empresa (o mesmo comportamento de "múltiplas empresas" descrito acima); se nenhuma coluna for identificada e o usuário não escolher uma manualmente, é exibido um campo para digitar o nome da empresa que vai constar no cabeçalho de todos os documentos daquela geração.

Valor por extenso (variáveis com o sufixo ext): o número da variável (aceita tanto formato brasileiro "1.500,00" quanto "1500.00") é convertido para texto por extenso no padrão de valor monetário, ex.: 1500,50 → "mil e quinhentos reais e cinquenta centavos".

Ordem dos passos do assistente: Empresas sempre aparece primeiro (exceto no modo Excel puro); Empregados/Sócios/Rubricas aparecem só se marcados como fonte do modelo; Planilha aparece se a fonte Excel estiver marcada ou se o texto do modelo contiver alguma variável {{excel.*}}, mesmo que a fonte não tenha sido marcada explicitamente.

Perguntas frequentes

A empresa de um empregado não aparece nas variáveis do documento gerado (campos {{empresa.*}} em branco)?
O código da empresa do empregado (em Empregados) precisa bater exatamente com o código cadastrado em Empresas. Confira se não há espaços a mais em um dos dois cadastros.
Consigo trocar a logo de uma empresa depois de já ter gerado documentos com ela?
Sim. A logo fica salva no cadastro da empresa (não no documento já gerado) — trocá-la ou removê-la na tela de Empresas do assistente afeta só as próximas gerações.
Por que meu PDF não abriu?
O navegador pode ter bloqueado o pop-up da janela de impressão, principalmente quando várias empresas geram várias janelas de uma vez. Permita pop-ups para esta página e clique em "Salvar PDF" novamente.

Dashboard e Histórico

Como usar

  1. O Dashboard abre ao entrar na ferramenta e mostra um resumo: total de modelos cadastrados, gerações feitas hoje, total de gerações e total de registros (documentos) já gerados, além dos modelos mais recentes e das últimas gerações.
  2. O Histórico lista todas as gerações já feitas (até as 100 mais recentes), com modelo usado, empresas envolvidas, quantidade de registros, tipo de cabeçalho, quem gerou e quando.

Funcionalidades

  • Quando a geração é de um Evento, o Histórico grava uma linha por modelo do evento (não uma linha só para o evento), permitindo ver individualmente quantos de cada documento foram emitidos.
  • O Histórico é só um registro do que já foi gerado — não guarda o PDF/Excel em si, apenas os metadados da geração (modelo, empresas, quantidade, cabeçalho, autor e data).
