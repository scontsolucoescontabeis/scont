O Gerenciador de Formulários reúne três formulários públicos de captação — Registro de Empresa, Alteração de Empresa e Registro de Empregado — com um painel interno para a equipe acompanhar, validar, editar e excluir tudo o que é recebido. Os formulários são páginas independentes (compartilháveis por link) que qualquer cliente preenche sem precisar de login; o painel de gestão, o histórico de edições e o navegador de arquivos do servidor exigem acesso ao portal.

Painel de Gestão de Formulários

Como usar

  1. Acesse Gerenciamento de Formulários pelo portal — a tela inicial lista todos os envios recebidos, mais recentes primeiro.
  2. Use o menu lateral para filtrar por tipo (Todos, Registro de Empresa, Alteração de Empresa, Registro de Empregado); use a busca por nome/CPF/e-mail e o filtro de Status (o padrão ao abrir a tela é mostrar só "Recebido").
  3. Clique em um card para abrir os Detalhes — inclui os sócios (registro/alteração) ou os dependentes (empregado) já buscados do banco.
  4. Use os botões rápidos do card: 📁 Docs (documentos anexados no Storage), 👁️ Ver (detalhes), ✏️ Editar, 📊 (exportar aquele registro para Excel) e 🗑️ (excluir).
  5. Em Editar, ajuste o Status (Recebido/Validado/Rejeitado), o Responsável e os campos do formulário; ao clicar em Salvar Alterações o sistema grava no banco, gera um PDF atualizado com os novos dados e registra o evento no histórico.
  6. Use Consulta CNAE na barra lateral para pesquisar por código ou descrição — copia o CNAE selecionado para a área de transferência (útil para colar no campo de atividade).
  7. Para gerar o link de um dos três formulários (para enviar ao cliente), use Links dos Formulários no topo da tela e clique no ícone de copiar — cada cópia gera um link com um token novo.

Funcionalidades

  • Atualização em tempo real: um novo envio ou uma edição feita por outra pessoa aparece na lista sem precisar recarregar a página.
  • Visibilidade por sub-permissão: usuários sem acesso de administrador só veem as abas "Registro/Alteração" e/ou "Registro de Empregado" conforme liberado para eles em Configurações — quem não tem nenhuma das duas nem enxerga a respectiva opção no menu.
  • Exclusão lógica: o botão excluir nunca apaga a linha do banco — marca o status como "excluido" (o card some da listagem) e grava o evento no histórico.
  • Exportação para Excel por registro individual, com as colunas já traduzidas para rótulos legíveis.
  • Visualizador de documentos por formulário: lista, pré-visualiza e baixa os arquivos que o cliente anexou (identificação dos sócios, documentos do empregado), sem precisar abrir o navegador de arquivos do servidor.

Perguntas frequentes

Excluí um formulário por engano — dá para recuperar?
Sim. A exclusão só muda o status para "excluido"; o registro continua no banco. É preciso pedir para alguém com acesso ao banco reverter o status manualmente, já que a tela não oferece um botão de "desfazer".
Por que não vejo os cards de Registro/Alteração de Empresa (ou de Empregado)?
Seu usuário não tem a sub-permissão correspondente liberada. Peça para um administrador ajustar em Configurações do portal.

Formulário de Registro de Empresa

Como usar

  1. Abra o link do formulário (gerado no Painel de Gestão ou pelo card correspondente na Central de Documentos) — não é preciso login.
  2. Preencha os blocos: Informações da Empresa (nome, propostas de nome alternativo, porte, capital social), Sede do Estabelecimento, Atividades (principal e secundárias).
  3. Em Dados dos Sócios, clique em + Adicionar Sócio para cada sócio; cada card exige nome, CPF, se é administrador, participação societária e o upload do documento de identificação (RG, CPF ou CNH).
  4. Leia e aceite o Termo de Consentimento LGPD e clique em Salvar e Enviar.
  5. Ao concluir, a tela mostra o ID da submissão e oferece um botão para compartilhar a confirmação por WhatsApp.

Funcionalidades

  • A soma das participações societárias precisa fechar exatamente 100% antes do envio ser aceito.
  • O campo de Regime de Partilha de Bens só aparece quando o sócio é marcado como casado ou em união estável.
  • Upload de documento por sócio limitado a PDF/JPG/PNG, até 5 MB por arquivo.
  • Ao enviar, o sistema gera automaticamente um PDF-resumo do formulário (sem precisar de servidor), salva o registro e os sócios no banco, envia os documentos para o Storage e dispara um e-mail de aviso para a equipe administrativa.
  • Este formulário não salva rascunho automático — diferente dos formulários de Alteração e de Empregado, se a página for fechada antes do envio o preenchimento é perdido.

Formulário de Alteração de Empresa

Como usar

  1. Abra o link do formulário e informe o nome legal da empresa.
  2. Para cada bloco (nome, nome fantasia, capital social, dados do estabelecimento, atividades, quadro societário), responda "Sim" apenas se aquilo for mudar — os campos daquele bloco só ficam visíveis e obrigatórios quando a resposta é "Sim".
  3. Se houver mudança no quadro societário, adicione um card por sócio afetado e escolha a Ação (Inclusão, Edição ou Exclusão) além dos dados do sócio.
  4. Aceite o Termo de Consentimento LGPD e envie.

Funcionalidades

  • Rascunho automático: dois segundos após qualquer alteração no formulário, o preenchimento é salvo sozinho vinculado a um token único gerado na URL (parâmetro ?token=).
  • Se a pessoa fechar a aba e reabrir o mesmo link (com o mesmo token), as respostas voltam automaticamente e um aviso confirma que o rascunho foi restaurado.
  • O rascunho é apagado assim que o envio é concluído com sucesso.
  • Gera PDF-resumo, salva sócios com a ação indicada e notifica a equipe administrativa por e-mail, no mesmo padrão do Registro de Empresa.

Perguntas frequentes

Perdi o link que eu estava usando para preencher — meu rascunho sumiu?
O rascunho fica vinculado ao token daquele link específico. Abrir o formulário do zero (sem o parâmetro token da sessão anterior) gera um token novo e começa um preenchimento em branco.

Formulário de Registro de Empregado

Como usar

  1. Abra o link do formulário e preencha os dados pessoais do empregado.
  2. Em Informações Familiares, responda se há filhos; se "Sim", a tabela de dependentes aparece — clique em + Adicionar Dependente para cada um (nome, CPF, nascimento, parentesco).
  3. Em Benefícios e Descontos, informe se é optante do Vale Transporte (e, se for, se autoriza o desconto de 6%) e os valores diários de VT/VA.
  4. Em Dados Contratuais, informe empresa, cargo, admissão, salário, dias e horário de trabalho.
  5. Em Documentação Exigida, envie os arquivos por categoria (Identificação, Familiares, Médicos) — cada campo aceita mais de um arquivo, inclusive em cliques separados.
  6. Aceite o Termo de Consentimento LGPD e envie.

Funcionalidades

  • Cada campo de upload acumula os arquivos escolhidos a cada seleção — não é preciso selecionar tudo de uma vez; dá para remover um arquivo específico antes de enviar.
  • Rascunho automático com restauração por token na URL, no mesmo padrão do formulário de Alteração de Empresa.
  • O e-mail de aviso de novo envio vai para a equipe de Pessoal/RH — endereço diferente do usado pelos formulários de Registro e Alteração de Empresa (equipe administrativa).

Histórico de Edições

Como usar

  1. Acesse Histórico de Edições pelo menu lateral do Gerenciador.
  2. Use a busca para filtrar por responsável ou nome do campo alterado, e o filtro de data para um dia específico.

Funcionalidades

  • Registra automaticamente todo salvamento feito pela tela de Edição (valor anterior → novo valor de status, quem editou, quando) e toda exclusão de formulário.
  • É um log de auditoria imutável — não existe edição nem exclusão de uma linha do histórico pela interface.

Central de Documentos e Arquivos do Servidor

Como usar

  1. A Central de Documentos é a porta de entrada: reúne, em cards, os três formulários de preenchimento e os atalhos para o Gerenciador e para os Arquivos do Servidor.
  2. Em Arquivos do Servidor, navegue pelas pastas do repositório de documentos usando o caminho (breadcrumb) no topo da tela.
  3. Use os botões de cada arquivo para baixar ou excluir, ou o botão de upload para enviar um arquivo novo na pasta atual.

Funcionalidades

  • Navegação em pastas com pré-visualização de arquivos (PDF/imagem) direto no navegador, sem precisar baixar primeiro.
  • Acesso de leitura e gestão de arquivos independente de qual formulário gerou o documento — útil para organizar ou limpar manualmente a estrutura de pastas do Storage.
