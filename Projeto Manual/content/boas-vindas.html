O Boas-Vindas gera uma página de apresentação personalizada para cada cliente novo — um guia com os departamentos da Scont (Fiscal, Pessoal, Contábil, Administrativo), orientações e contatos, com um link único que também exibe os dados cadastrais daquele cliente. A administração (criação, envio e acompanhamento dos links) fica em admin/admin.html; a página que o cliente recebe é o index.html da ferramenta.

Criar Apresentação

Como usar

  1. Digite o CNPJ do cliente e clique em Buscar (ou tecle Enter) para preencher automaticamente Razão Social, Ramo de Atividade, Porte, Telefone, Regime (quando optante pelo Simples) e os CNAEs principal/secundários a partir da Receita Federal. Campos já preenchidos manualmente não são sobrescritos por valores vazios.
  2. Confira/ajuste Regime tributário e Porte.
  3. Confirme o CNAE Principal (obrigatório) — se a busca automática não tiver preenchido, clique em Consultar para abrir a lista de CNAEs e escolher manualmente. Adicione CNAEs secundários pelo mesmo mecanismo, um de cada vez.
  4. Preencha os dados de contato do cliente: Nome e E-mail são obrigatórios; Cargo e Telefone são opcionais (mas o Telefone é necessário se quiser enviar por WhatsApp).
  5. Escreva, se quiser, uma mensagem de boas-vindas personalizada (até 400 caracteres) — ela substitui o texto padrão no topo da página do cliente.
  6. Marque como a apresentação deve ser enviada: E-mail (marcado por padrão, dispara sozinho ao gerar) e/ou WhatsApp (abre uma conversa no WhatsApp Web/App com a mensagem já pronta — o envio final ainda depende de você clicar em enviar por lá).
  7. Clique em Gerar Apresentação. O sistema mostra o link exclusivo do cliente, com botões para copiar, visualizar, reenviar e-mail ou começar uma nova apresentação.

Funcionalidades

  • Busca automática de dados cadastrais por CNPJ (BrasilAPI) — inclui CNAE principal e todos os secundários informados pela Receita.
  • Consulta manual de CNAE por código ou nome da atividade, com busca de texto na lista completa (mesma base usada em outras ferramentas do portal).
  • E-mail de boas-vindas enviado automaticamente na criação, através de uma função do sistema (não abre um cliente de e-mail local).
  • WhatsApp: abre uma conversa já com a mensagem redigida (saudação + nome da empresa + link); não é enviado sozinho, é preciso confirmar o envio na própria conversa.
  • Botão Reenviar Email na tela de resultado, para reenviar a mesma apresentação sem precisar recriá-la (funciona enquanto a tela não for recarregada/fechada).
  • Link exclusivo por cliente, no formato index.html?id=..., gerado automaticamente ao salvar.

Perguntas frequentes

A busca por CNPJ não encontrou a empresa, o que fazer?
Preencha os campos manualmente — Razão Social, Regime, Porte e CNAE Principal continuam obrigatórios mesmo sem a busca automática.
Marquei WhatsApp mas nada abriu. Por quê?
O telefone do contato precisa estar preenchido. Sem telefone, a apresentação é criada normalmente, só o envio por WhatsApp é pulado (aparece um aviso na tela de resultado).
Posso editar uma apresentação depois de criada?
Não há tela de edição. Se os dados estiverem errados, crie uma nova apresentação e desative a antiga no Histórico para não haver dois links ativos para o mesmo cliente.

Histórico

Como usar

  1. Abra a aba Histórico no menu lateral para ver todas as apresentações já criadas, mais recentes primeiro.
  2. Use a busca para filtrar por empresa, contato, e-mail ou CNPJ, e o seletor de status para ver só Ativas (padrão), só Desativadas ou Todas.
  3. Em cada linha ativa: visualizar o link, copiar o link, enviar por WhatsApp (se houver telefone cadastrado), desativar ou excluir.
  4. Em linhas desativadas, as ações disponíveis são reativar e excluir.

Funcionalidades

  • Três indicadores no topo: total de apresentações ativas, soma de acessos das apresentações ativas e quantas foram criadas no mês corrente — todos recalculados a partir da lista carregada.
  • Desativar é reversível: o link do cliente para de abrir a apresentação personalizada (cai no modo genérico, sem os dados cadastrais) até alguém reativar. É a forma recomendada de "encerrar" um link sem perder o histórico de acessos.
  • Excluir é permanente — remove o registro do banco, não há como recuperar.
  • O contador de acessos é incrementado automaticamente quando o cliente abre o link (não exige nenhuma ação do administrador).

Perguntas frequentes

Criei uma apresentação e o cliente acabou de acessar — o contador não mudou na tela.
O Histórico não atualiza em tempo real. Troque de aba (ex.: vá em Criar Apresentação e volte) ou recarregue a página para ver o número de acessos mais recente.
Desativar apaga os dados da empresa?
Não. Desativar só bloqueia o link — os dados continuam no Histórico (na lista "Desativadas") e podem ser reativados a qualquer momento.
Quantas apresentações a lista mostra?
As 50 mais recentes. Use a busca para localizar uma apresentação específica se ela não aparecer na lista.

O que o cliente vê

Como usar

  1. O cliente recebe o link (por e-mail ou WhatsApp) e abre a página de apresentação da Scont, com um menu fixo para navegar entre os departamentos: Fiscal, Pessoal, Contábil, Administrativo, Ferramentas/Serviços, Segurança e Contatos.
  2. Se o link tiver o identificador da apresentação dele (o link gerado no admin), a página soma uma seção inicial de Dados Cadastrais com o que foi cadastrado (razão social, CNPJ, inscrição estadual, regime, porte, ramo, CNAE principal e secundários, e o contato responsável) — e a saudação no topo passa a citar o nome da empresa.
  3. O cliente navega livremente pelo guia, pode voltar ao topo, imprimir a página (o menu e outros elementos de navegação somem na impressão) e usar o link quantas vezes quiser.

Funcionalidades

  • Sem identificador válido na URL (link genérico, digitado direto ou apresentação desativada/excluída), a página exibe o guia padrão da Scont, sem a seção de dados cadastrais e sem personalização — não trava nem mostra erro para o cliente.
  • Com identificador válido: saudação personalizada ("Bem-vinda à Scont, [Empresa]"), mensagem de boas-vindas customizada (ou a padrão, se não foi escrita nenhuma), selo "Apresentação personalizada" no canto da tela e chips com CNPJ/Regime/Porte logo abaixo do título.
  • Cada abertura do link registra um acesso automaticamente, usado para compor os números do Histórico no admin.
  • Barra de progresso de leitura, botão de voltar ao topo e destaque automático do departamento atual no menu conforme o cliente rola a página.

Perguntas frequentes

O cliente perde acesso se eu desativar a apresentação depois de enviada?
Sim — o link continua abrindo, mas volta a mostrar o guia genérico, sem os dados cadastrais nem a saudação personalizada. Reativando no Histórico, volta ao normal.
O cliente vê quantas vezes já acessou o link?
Não. O contador de acessos só aparece para a equipe, na tela de Histórico do admin.
