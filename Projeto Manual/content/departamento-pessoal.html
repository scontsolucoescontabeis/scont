O Departamento Pessoal é um guia de consulta rápida para os processos operacionais do setor: para cada situação, ele mostra o fluxograma do processo, o passo a passo com o caminho exato dentro do sistema Domínio, os documentos envolvidos e os pontos de atenção legais. Hoje a ferramenta reúne os fluxos de Rescisão; é organizada por categorias no menu lateral, preparada para receber outras rotinas do DP no futuro.

Fluxos de Rescisão

Como usar

  1. No menu lateral, clique na categoria Rescisão para abrir a lista de fluxos e escolha o tipo de desligamento correspondente ao caso (ex.: dispensa sem justa causa, pedido de demissão, acordo mútuo, justa causa).
  2. No topo da tela, confira os três cartões de resumo: Prazo de pagamento, Observação sobre o aviso prévio e Referências legais daquele tipo de rescisão.
  3. Veja o fluxograma do processo para ter a visão geral das etapas de ponta a ponta.
  4. Abra o Passo a passo clicando em cada etapa para expandir — cada tarefa traz o caminho de menus e telas a seguir no sistema Domínio.
  5. Quando existirem, confira também os cartões Considerações legais e operacionais e Checklist de documentos ao final da página.

Funcionalidades

  • Seis fluxos de rescisão documentados: dispensa sem justa causa com aviso trabalhado, dispensa sem justa causa com aviso indenizado, pedido de demissão com aviso trabalhado, pedido de demissão com desconto/dispensa do aviso, rescisão por acordo entre as partes e rescisão por justa causa.
  • Cada etapa do passo a passo é uma seção retrátil (clique para abrir/fechar), o que permite acompanhar o processo sem poluir a tela com todo o conteúdo de uma vez.
  • O fluxo de "pedido de demissão — desconto ou dispensa do aviso" traz uma bifurcação no fluxograma para as três situações possíveis do aviso prévio (desconto total, dispensa pela empresa, novo emprego comprovado).
  • É uma ferramenta só de consulta: não há cadastro de funcionário, cálculo de verbas nem lançamento de dados — todo o processamento da rescisão continua sendo feito no sistema Domínio; aqui fica só o roteiro de como conduzir cada etapa.

Perguntas frequentes

Por que só aparece a categoria Rescisão no menu?
Por enquanto só os fluxos de rescisão foram documentados. A tela já está preparada para receber outras categorias do Departamento Pessoal (admissão, férias etc.) conforme forem escritas.
Dá para preencher dados do funcionário ou gerar algum documento por aqui?
Não. A ferramenta é um guia de referência com o passo a passo e o fluxograma de cada processo — o cadastro, cálculo e emissão de documentos continuam sendo feitos no sistema Domínio, seguindo o caminho indicado em cada etapa.
Os prazos e observações legais mostrados nos cartões são atualizados automaticamente?
Não, é conteúdo fixo escrito a partir da documentação do processo. Se a legislação ou o procedimento interno mudar, o conteúdo precisa ser atualizado manualmente.
